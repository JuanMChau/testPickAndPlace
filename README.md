This is a basic prototype of a VR sorting task built in Unity, intended to mimic an experiment used for naturalistic working memory (WM) research.
 
> **Note:** This is a rough prototype put together in a very short amount of time. Expect rough edges, missing features and bugs. It is a proof of concept, not a finished or validated experiment.
 
## Baseline
 
This project uses the [onlineVR-toolbox](https://github.com/lkumle/onlineVR-toolbox) as its baseline. The toolbox provides the Unity package, web app files and data handling for running VR experiments online. See its [step-by-step tutorials](https://lkumle.github.io/onlineVRtoolbox_tutorials/) for setup details.
 
If you use this work, please cite the original toolbox:
 
> Kumle, L., Brazier, A., Kovoor, J., Keil, J. S., Nobre, K., & Draschkow, D. (2025, July 18). *Running Virtual Reality Experiments Online: A Brief Introduction and Tutorial*. https://doi.org/10.31219/osf.io/hax47_v1
 
## What's in this prototype

This prototype uses the onlineVR-toolbox to successfully encrypt data, and XR components to pick and place items.
